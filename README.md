# Keepsake

「残り色」和「照片花邊塗鴉」合併後的版本。導入照片，只留下想要的顏色、畫上手繪花邊、貼圖和文字，加上拍立得外框，再存回相簿。可以加到手機主畫面當 App 用，沒有網路也能開。

## 使用流程

**首頁選功能 → 選照片 → 裁切 → 編輯 → 外框 → 匯出**

| 步驟 | 內容 |
|---|---|
| 首頁 | 選「残り色」（留色）或「落書き」（花邊），接著選照片。也可以繼續上次的作品，或用範例照片試試 |
| 裁切 | 比例、旋轉、拉直、翻轉；不需要就直接按「下一步」 |
| 編輯：残り色 | 點照片選色後才會套用黑白留色，最多 4 色，每色各自調整色相範圍、邊緣柔和、飽和度門檻、鮮豔度；整體黑白對比 |
| 編輯：落書き | 畫筆（5 種線條、4 種質感、微光、灑亮片）、貼圖（15 種）、文字（12 種字型）、橡皮擦、一鍵風格 |
| 外框（兩種功能共用） | 無邊框／白邊／拍立得／色卡，白／黑／主色／自訂顏色，寬度可調，可在下方印色碼 |
| 匯出 | 儲存到相簿／分享、下載，或長按圖片儲存 |

上方的步驟名稱可以直接點，跳回那一步調整；眼睛按鈕按住可看原圖。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 小工具本體 |
| `manifest.webmanifest` | 讓手機知道這是 App（名稱、圖示、顏色） |
| `sw.js` | 離線功能，開過一次之後沒網路也能用 |
| `icons/` | 主畫面圖示 |
| `.nojekyll` | 讓 GitHub 直接照原樣放出檔案 |

## 架設到 GitHub Pages

1. 登入 GitHub，右上角 **+** → **New repository**，取一個英文名字（例如 `keepsake`），選 **Public**，按 **Create repository**。
2. 點 **uploading an existing file**，把這個資料夾裡的**所有檔案和 `icons` 資料夾**一起拖進去，按 **Commit changes**。
3. **Settings** → **Pages** → Source 選 **Deploy from a branch**，Branch 選 **main**、**/ (root)**，按 **Save**。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/keepsake/`。

如果想直接取代原本的 color-keep，把這些檔案上傳覆蓋到 color-keep 的 repository 即可（原本的 icon-32.png 等舊圖示可以留著或刪掉）。

## 使用上要知道的事

- **每個人的作品只存在自己的手機裡**，不會上傳到任何地方。
- 存圖時按「儲存到相簿／分享」會跳出系統分享選單，選「儲存影像」就會進相簿。也可以長按圖片選「加入照片」。
- 第一次打開要有網路；之後沒網路也能用。

## 之後想更新內容

1. 在 GitHub 上把新的 `index.html` 上傳覆蓋。
2. 打開 `sw.js`，把第一行的 `keepsake-v1` 改成 `keepsake-v2`（每次更新加 1）。
